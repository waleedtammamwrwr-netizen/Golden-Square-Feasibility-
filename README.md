# Golden Square - Growth Plan 2027-2031

Interactive presentation of the Golden Square Engineering Consultants growth plan.

Open `index.html` in a browser (download it, or enable GitHub Pages) and use the **Adjust the plan** panel: fees, projects won, productivity, collection days, tax and VAT. Every slide recalculates.

Slides: Plan, Pipeline, Revenue, Team, Staff dashboard, P&L, Cash flow, Organisation.
